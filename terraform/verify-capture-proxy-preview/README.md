# Terraform capture proxy copy

This directory uses the same reviewed candidate handler and IAM-signed request model as the standalone Terraform module. See the [current integration README](../../README.md) for contract, policy, security limits and acceptance gates.

Requires Terraform >=1.5, AWS provider ~>6.73, archive provider ~>2.8. Source runtime: Node24. No deployment or live acceptance is established by a successful local validation.
