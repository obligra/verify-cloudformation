# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in these templates, please report it to:

**security@obligra.ai**

Do not open a public issue for security vulnerabilities.

## Response Timeline

We will acknowledge receipt within 48 hours and provide an initial assessment within 5 business days.

## Scope

This policy covers:

- CloudFormation template security issues
- IAM policy over-permissions
- Sensitive data exposure in logging
- Insecure default configurations

## Out of Scope

- Vulnerabilities in the Obligra Verify platform itself (report separately to security@obligra.ai)
- Issues in customer-modified copies of these templates
- AWS service-level vulnerabilities (report to AWS)
